# A.U.R.O.R.A

**Autonomous Unified Responsive Operating & Reasoning Assistant**

The runnable desktop assistant lives in [`Aurora-Ai/`](./Aurora-Ai/). Its
Windows release is packaged as a single A.U.R.O.R.A `.exe`; source installation
is available for developers and other platforms. See the desktop guide for
configuration, capabilities, and the action/plugin contracts:

```bash
cd Aurora-Ai
python setup.py
python main.py
```

The supplied desktop-compatible Brahma integrations are active A.U.R.O.R.A
plugins: calendar scheduling, daily briefing, circuit schematics, Spotify,
video publishing, calorie tracking, and workout tracking. Their original
Android and server-only sources remain reference material and are not part of
the Windows executable. Tagged releases publish only the Windows `.exe`.
